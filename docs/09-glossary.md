# 09 — Glossary

| Term | Meaning |
|---|---|
| **AlkG** | Swiss Federal Alcohol Act (Alkoholgesetz, SR 680) |
| **APNs** | Apple Push Notification service (from iPhone OS 3.0, 2009) |
| **BAKOM** | Swiss Federal Office of Communications |
| **BankG / BankV** | Swiss Banking Act / Banking Ordinance |
| **Closed loop** | Payment instrument usable only with the issuer itself |
| **DCB** | Direct Carrier Billing — charging a purchase to the mobile phone bill or prepaid balance |
| **DLR** | Delivery report of an SMS; for premium SMS it confirms billing |
| **DSG** | Swiss Federal Act on Data Protection (1992 version in 2008) |
| **EBK** | Swiss Federal Banking Commission (until 2008, then FINMA) |
| **EDÖB** | Federal Data Protection and Information Commissioner |
| **Entitlement** | Pre-paid right (ticket, guest list) stored on the member account |
| **FDV** | Ordinance on Telecommunications Services |
| **FMG** | Swiss Telecommunications Act |
| **GwG** | Swiss Anti-Money Laundering Act |
| **HMAC** | Keyed-hash message authentication code |
| **HOTP** | HMAC-based One-Time Password, RFC 4226 (2005) |
| **Look-ahead window** | Number of future counter values the server accepts to tolerate unused codes |
| **MO / MT** | Mobile-originated (guest → server) / mobile-terminated (server → guest) SMS |
| **Mehrwertdienst** | Value-added telecom service billed via the carrier |
| **MSISDN** | Mobile phone number in international format (`+4179…`) |
| **PBV** | Swiss Price Disclosure Ordinance |
| **plist** | Apple property list format, natively parsed by iPhone OS |
| **PSP** | Payment Service Provider (card acquiring gateway) |
| **Rappen** | 1/100 CHF; all amounts are stored as integer Rappen |
| **Short number** | 3–5 digit SMS number assigned by a carrier/aggregator |
| **TOTP** | Time-based OTP, RFC 6238 (2011) — not used, did not exist as RFC in 2008 |
| **Venue node** | Local server in the club providing offline operation |
| **Web clip** | Home-screen bookmark of a web app on the iPhone |
